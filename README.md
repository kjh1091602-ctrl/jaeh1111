# 세금 · 인원확인 디스코드 봇

세금 인증 관리 + 전쟁 인원확인 기능을 갖춘 디스코드 봇입니다.

## 기능 요약

- **시민 관리**: `/시민 추가·제거·수정` — 마크닉 ↔ 디스코드 계정 연동, 왕/시민 직급 관리
- **인원확인**: 버튼(접속/퇴장 × 왕/시민)로 실시간 접속 현황 표시, 왕 포함 3명 이상이면 자동으로 "⚔️ 접근금지" 빨간색 알림
- **세금 시스템**: 버튼 → 팝업창(닉네임+스크린샷 첨부) → 관리자 승인/반려 → 신청자 DM 알림 + 매일 자정 미납자 명단 자동 게시

---

## 1. 디스코드 봇 생성 (최초 1회)

1. https://discord.com/developers/applications 접속 → **New Application** 클릭 → 이름 입력 (예: 세금봇)
2. 왼쪽 메뉴 **Bot** 탭 → **Reset Token** → 나오는 토큰을 복사해둠 (⚠️ 한 번만 보여줌, 안전하게 보관)
3. 같은 Bot 탭에서 아래 항목은 **전부 꺼둔 채로 둡니다** (이 봇은 메시지 내용을 읽을 필요가 없어요):
   - Presence Intent, Server Members Intent, Message Content Intent → 모두 OFF 유지
4. 왼쪽 메뉴 **OAuth2 → General**에서 **Application ID (Client ID)** 복사해둠

## 2. 서버에 봇 초대

1. 왼쪽 메뉴 **OAuth2 → URL Generator**
2. **SCOPES**: `bot`, `applications.commands` 체크
3. **BOT PERMISSIONS**: 아래 항목 체크
   - Send Messages
   - Embed Links
   - Attach Files
   - Read Message History
   - Manage Messages (버튼 메시지 수정용)
   - Use Slash Commands
4. 하단에 생성된 URL을 브라우저에 붙여넣고 봇을 초대할 서버 선택 → 승인

## 3. 프로젝트 설치

```bash
# 압축 해제한 폴더로 이동
cd taxbot

# 패키지 설치
npm install

# .env 파일 생성
cp .env.example .env
```

`.env` 파일을 열어서 아래 값을 채워주세요:

```
DISCORD_TOKEN=1번에서 복사한 봇 토큰
CLIENT_ID=1번에서 복사한 Application ID
GUILD_ID=(선택) 테스트할 서버 ID — 입력하면 명령어가 즉시 반영됩니다
```

> 서버 ID는 디스코드 앱에서 개발자 모드를 켠 뒤(설정 → 고급 → 개발자 모드), 서버 아이콘 우클릭 → "서버 ID 복사"로 확인할 수 있습니다.
> `GUILD_ID`를 비워두면 모든 서버에 전역 등록되지만, 명령어가 실제로 뜨기까지 최대 1시간이 걸릴 수 있습니다. **테스트 중엔 GUILD_ID를 채워두는 걸 추천해요.**

## 4. 슬래시 명령어 등록 + 봇 실행

```bash
# 슬래시 명령어를 디스코드에 등록 (설정을 바꿀 때마다 다시 실행)
npm run deploy

# 봇 실행
npm start
```

콘솔에 `✅ (봇이름) 로그인 완료` 가 뜨면 정상 작동 중입니다.

## 5. 서버에서 바로 세팅하기 (관리자)

디스코드 서버에서 **서버 관리 권한**이 있는 계정으로 아래 순서대로 입력하세요.

1. **세금 채널 지정** (세금 인증글이 올라올 채널에서 실행)
   ```
   /설정 세금채널 채널:#세금인증
   ```
   → 실행하는 즉시 해당 채널에 "💰 세금 안내" + [세금 인증하기] 버튼이 자동 게시됩니다.

2. **세금 금액 설정** (만원 단위)
   ```
   /세금 수정 금액:200
   ```

3. **시민 등록** (마크닉·디스코드 계정 연동)
   ```
   /시민 추가 마크닉:Steve_King 디코:@유저1 직급:왕
   /시민 추가 마크닉:Notch123 디코:@유저2 직급:시민
   ```

4. **인원확인 게시판 생성** (전쟁 체크용 채널에서 실행)
   ```
   /인원관리 생성
   ```
   → 이 채널에 접속 현황 embed + 버튼 4개가 고정 게시됩니다. 이후 이 메시지는 계속 수정(edit)되며 갱신됩니다.

이제 시민들은:
- 세금 채널의 **[세금 인증하기]** 버튼을 눌러 마크닉 + 스크린샷 제출
- 인원확인 채널의 **[접속(왕)/접속(시민)]** 버튼으로 접속 체크, **[퇴장]** 버튼으로 퇴장 처리

## 명령어 전체 목록

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/시민 추가 마크닉 디코 [직급]` | 시민 등록 | 서버 관리 |
| `/시민 제거 마크닉` | 시민 비활성화 (기록은 보존) | 서버 관리 |
| `/시민 수정 마크닉 [새마크닉] [새디코] [직급]` | 시민 정보 수정 | 서버 관리 |
| `/설정 세금채널 채널` | 세금 인증/현황 게시 채널 지정 + 안내 자동 게시 | 서버 관리 |
| `/세금 수정 금액` | 세금 금액 변경 (만원 단위) | 서버 관리 |
| `/세금 현황` | 미납자 명단 즉시 게시 (자정 자동 게시와 별개로 수동 실행) | 서버 관리 |
| `/인원관리 생성` | 이 채널에 인원확인 게시판 생성 | 서버 관리 |
| `/인원관리 삭제 대상` | 접속 목록에서 특정 인원 강제 제거 | 서버 관리 |

버튼(누구나 사용 가능, 단 본인이 등록된 직급에 맞는 버튼만 동작):
- 접속(왕) / 퇴장(왕) / 접속(시민) / 퇴장(시민)
- 세금 인증하기 → 팝업창에서 마크닉 + 스크린샷 제출
- (관리자 전용) 세금 인증 요청 아래 ✅ 승인 / ❌ 반려

## 자주 발생할 수 있는 문제

- **`SQLite is an experimental feature...` 경고가 떠요** → 정상입니다, 에러가 아니에요. Node.js 내장 SQLite 기능을 쓰고 있어서 뜨는 안내 문구일 뿐, 봇 작동에는 문제 없습니다.
- **Node.js 버전이 너무 낮다는 오류가 나요** → 이 봇은 Node.js 내장 SQLite 기능을 사용하기 때문에 **Node.js 22.5 이상**이 필요합니다. `node -v`로 버전 확인 후, 낮다면 https://nodejs.org 에서 최신 LTS 버전을 새로 설치해주세요.
- **명령어가 서버에 안 보여요** → `npm run deploy`를 실행했는지 확인. `GUILD_ID`를 비워뒀다면 최대 1시간 대기.
- **버튼을 눌러도 반응이 없어요** → `npm start`로 봇이 실제로 켜져 있는지 확인 (터미널을 계속 켜두거나, 아래 "24시간 운영" 참고)
- **세금 인증 모달에서 파일 첨부가 안 보여요** → `discord.js` 버전이 `14.27.0` 이상인지 확인 (`npm ls discord.js`). 이 기능은 최근에 추가된 기능이라 구버전 클라이언트/라이브러리에선 지원하지 않을 수 있습니다.
- **시민 제거/수정이 "등록되지 않은 마크닉"이라고 나와요** → 마크닉은 대소문자까지 정확히 일치해야 합니다. `/시민 추가` 시 입력한 철자 그대로 입력해주세요.

## 24시간 운영하려면

지금 이 코드는 로컬(내 컴퓨터)에서 `npm start`로 켜둔 동안만 작동해요. 컴퓨터를 끄면 봇도 꺼집니다. 계속 켜두려면 Railway, Render, 오라클 클라우드 무료 VM 같은 호스팅 서비스에 올리거나, 개인 서버(VPS)에 `pm2` 같은 프로세스 매니저로 상시 실행하는 걸 추천해요. 필요하시면 배포 방법도 안내해드릴게요.
